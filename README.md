# Pengyi Xiao - Academic Homepage

Static academic homepage for GitHub Pages, inspired by the structure of
[knightnemo.github.io](https://github.com/knightnemo/knightnemo.github.io).

The page content follows `academic-cv.pdf`; the separate internship section is
intentionally omitted, and the current research affiliation is shown
as **RA member of Tsinghua VIN Lab**. Typography uses Comic Sans MS with system
fallbacks, plus restrained glass, gradient, hover, and scroll-reveal effects.

## Publish

1. Create a public repository named `Pengyi-Xiao.github.io` on GitHub.
2. Push the contents of this directory to the repository's `main` branch.
3. In **Settings > Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

The site will be available at `https://pengyi-xiao.github.io/`.
